关于我

👋 简介

我是一名贴近业务的数据分析师。我相信数据的价值不在取数本身，而在回答业务问题——所以我的工作从理解业务开始：分摊规则怎么定、口径为什么对不上、指标异常背后是哪个业务动作。

过去几年，我的工作聚焦在数据体系搭建、数据工作流与 BI：从数据获取、数仓开发到调度运维、数据治理的全链路，再到指标体系与可视化看板，能把自己的业务想法亲手落地成数据，而不是把需求转手给别人。

现在，我正在向 BI + AI 转型：探索用大模型重塑分析工作流——智能问数、AI 报告生成、指标异动智能归因。我相信 BI 的确定性 + AI 的灵活性，是数据分析的下一个形态。

分析方法

01

5W2H 分析

从 What / Why / Who / When / Where / How / How much 七个维度全面定义业务问题，是需求拆解的第一步。

02

杜邦分析法

将核心指标逐层拆解为子指标，定位经营问题的驱动因素，常用于营收与利润分析。

03

流量漏斗分析

沿用户路径（曝光→点击→访问→加购→下单→支付）逐层度量转化率与流失率，定位流量损耗环节，指导优化优先级。

04

RFM 模型

用最近一次消费（Recency）、频次（Frequency）、金额（Monetary）对用户分层，支撑精细化运营与差异化触达。

05

AARRR 海盗指标

获客（Acquisition）、激活（Activation）、留存（Retention）、变现（Revenue）、推荐（Referral）——用户增长分析的完整框架。

06

A/B 实验

假设→分流→检验→决策。关注样本量、显著性水平与辛普森悖论等陷阱，用数据验证策略有效性。

07

同期群分析（Cohort）

按获客时间或特征分组，追踪不同 cohort 的留存与行为差异，比整体均值更能暴露真实趋势。

08

归因分析

首次/末次触点、线性、时间衰减等归因模型，评估各渠道与动作对转化的真实贡献。

09

对比与下钻分析

横向对比（竞对/渠道/人群）、纵向对比（同比/环比），配合维度下钻逐层定位问题根因。

BI 与数据体系

我深耕多年的领域：数据体系搭建、工作流与可视化。

📐 指标体系设计

OSM 模型（目标→策略→度量）：先明确业务目标，再定策略，最后落到可度量的指标。北极星指标 + 派生指标树，保证「看见的数字都能回答业务问题」。

🗂️ 数据建模

星型模型：事实表（交易、行为）+ 维度表（用户、商品、时间）。在 Power BI 中使用 DAX 构建度量值，遵循「度量值与计算列」的取舍原则；Tableau 中善用 LOD 表达式处理不同粒度的聚合。

🖥️ 看板设计原则

  • 一屏一个主题：概览→诊断→明细的三层下钻结构
  • 图表选型：趋势用折线、构成用堆叠/占比、对比用条形、分布用直方
  • 5 秒原则：核心 KPI 放在最左上，异常用颜色预警

🔄 报表工作流自动化

让数据自己跑起来：定时调度 + 每日数据推送 + 自动化报表分发。从「人找数」到「数找人」，把分析师从重复取数中解放出来。

AI 能力

正在系统学习的方向：用大模型武装分析工作。

💬 LLM 基础

理解大模型的能力边界：上下文窗口、幻觉、温度参数——知道 AI 擅长什么、什么时候不可信，是用好它的前提。

🧠 Prompt 工程

结构化提示词：角色 + 背景 + 任务 + 输出格式。经验：给模型提供表结构 DDL 和示例数据，SQL 生成准确率大幅提升。

🤖 AI Agent 与自动化

Agent = LLM + 工具 + 循环。探索用 Agent 串联取数、清洗、分析环节，把重复性分析工作交给流程完成。

BI + AI 转型方向

我正在探索的下一站：BI 的确定性 + AI 的灵活性。

🗣️ ChatBI / 智能问数

用自然语言直接查数：「上个月华东区销售额环比多少？」AI 翻译成 SQL 并返回图表。业务自助取数的终极形态，也是我重点关注的落地场景。

📝 AI 报告生成

指标数据喂给大模型，自动生成日报/周报初稿——数字描述、异动提示、图表配文，人只做最后的洞察提炼与业务判断。

🔎 指标异动智能归因

销售额跌了 8%，AI 自动拆解维度（地区×品类×渠道）定位异动来源，把过去半天的下钻分析压缩到几分钟。

🤖 分析 Agent 工作流

把「取数 → 清洗 → 分析 → 成文」整条链路编排成 Agent 流程，基于我搭的数据体系运行——数据地基是我打的，AI 才跑得稳。
