关于我

👋 简介

我是一名从业务一线走出来的数据人。我相信数据的价值不在取数本身，而在回答业务问题——所以我的工作从理解业务开始：分摊规则怎么定、口径为什么对不上、指标异常背后是哪个业务动作。

我的路径跨了五个行业：制药供应链起步，转型数据后在 BI 公司做工程与项目交付，在阿里巴巴本地生活做经营分析，在智联招聘带城市运营团队，最近四年多在跨境电商任数据部主管——主导经营数据体系、数据治理与 AI 落地。业务、数据、管理三条线都亲手做过。

现在，我正在向 BI + AI 转型：探索用大模型重塑分析工作流——智能问数、AI 报告生成、指标异动智能归因。我相信 BI 的确定性 + AI 的灵活性，是数据分析的下一个形态。

重点项目

每个项目按「背景 → 做法 → 结果」呈现，重点展示最近四年的体系级项目。

🏗️ 企业级经营数据体系与治理建设

背景：销售、广告、库存、费用、成本和利润数据分散在多系统与人工表格，核心数据缺失、映射不完整、口径不统一、利润核算不清晰。

做法：按数据源特点建立接口 / 平台导出 / 自动化 / RPA 采集链路，梳理血缘关系；统一平台、店铺、SKU、供应商主数据关系与各业务口径，按 ODS / DWD / DWS / ADS 分层沉淀清洗、映射、分摊与汇总逻辑；开发 30+ 核心报表，建立权限规则与数据刷新、结果校验、异常检查机制。

30+ 核心报表ODS→ADS 分层全链路血缘可追溯

结果：经营数据从人工统计转向统一、可追溯、持续监控的数据底座。

🚨 经营数据预警与 AI 异常归因 Agent

背景：依赖人工每日盯盘，异常发现不及时、责任人不清晰、处理闭环不足。

做法：用 SQL 编写销售、利润、库存、广告、产品质量与市场竞争监控逻辑；n8n 提取数据、编排任务，异常结果交 AI 分析与原因归因；异常类型、触发原因、影响范围和责任人整理后通过钉钉精准触达。

SQL 监控规则化n8n 编排AI 归因钉钉触达

结果：人工盯盘升级为「规则监控 + 自动编排 + AI 辅助分析 + 责任人触达」的闭环流程。

💰 财务对账与索赔自动化

背景：平台扣费和账单复杂，财务对账依赖人工，历史索赔规则分散，核对效率低且异常扣费易遗漏。

做法：梳理扣费、PO 订单、账单、合同价格与历史索赔记录，拆解 Shortage Claim、Overbilling、Price Claim 等索赔规则；搭建自动化对账与索赔筛选流程，自动比对识别异常扣费与可索赔事项。

每年挽回数十万美元人工核对 -90%

结果：财务管理从人工复核转向规则化、自动化、可追溯。

💵 现金流分析与资金占用监控

背景：财务分析侧重利润结果，无法判断现金流健康度；备货、库存占用、销售回款、平台结算等资金信息缺少统一分析。

做法：基于统一口径整理销售回款、平台结算、采购付款、库存占用与费用支出数据，明确资金流入、流出、占用和回款周期逻辑；搭建现金流分析报表，按平台、店铺、产品、时间维度分析资金变化与周转。

现金流健康度可判断前瞻性资金支持

结果：为备货、库存控制、付款安排和经营节奏提供前瞻性数据支持。

分析方法

01

5W2H 分析

从 What / Why / Who / When / Where / How / How much 七个维度全面定义业务问题，是需求拆解的第一步。

02

杜邦分析法

将核心指标逐层拆解为子指标，定位经营问题的驱动因素，常用于营收与利润分析。

03

流量漏斗分析

沿用户路径（曝光→点击→访问→加购→下单→支付）逐层度量转化率与流失率，定位流量损耗环节，指导优化优先级。

04

RFM 模型

用最近一次消费（Recency）、频次（Frequency）、金额（Monetary）对用户分层，支撑精细化运营与差异化触达。

05

AARRR 海盗指标

获客（Acquisition）、激活（Activation）、留存（Retention）、变现（Revenue）、推荐（Referral）——用户增长分析的完整框架。

06

A/B 实验

假设→分流→检验→决策。关注样本量、显著性水平与辛普森悖论等陷阱，用数据验证策略有效性。

07

同期群分析（Cohort）

按获客时间或特征分组，追踪不同 cohort 的留存与行为差异，比整体均值更能暴露真实趋势。

08

归因分析

首次/末次触点、线性、时间衰减等归因模型，评估各渠道与动作对转化的真实贡献。

09

对比与下钻分析

横向对比（竞对/渠道/人群）、纵向对比（同比/环比），配合维度下钻逐层定位问题根因。

BI 与数据体系

我深耕多年的领域：数据体系搭建、工作流与可视化。

📐 指标体系设计

OSM 模型（目标→策略→度量）：先明确业务目标，再定策略，最后落到可度量的指标。北极星指标 + 派生指标树，保证「看见的数字都能回答业务问题」。

🗂️ 数据建模

星型模型：事实表（交易、行为）+ 维度表（用户、商品、时间）。在 Power BI 中使用 DAX 构建度量值，遵循「度量值与计算列」的取舍原则；Tableau 中善用 LOD 表达式处理不同粒度的聚合。

🖥️ 看板设计原则

  • 一屏一个主题：概览→诊断→明细的三层下钻结构
  • 图表选型：趋势用折线、构成用堆叠/占比、对比用条形、分布用直方
  • 5 秒原则：核心 KPI 放在最左上，异常用颜色预警

🔄 报表工作流自动化

让数据自己跑起来：定时调度 + 每日数据推送 + 自动化报表分发。从「人找数」到「数找人」，把分析师从重复取数中解放出来。

AI 能力

正在系统学习的方向：用大模型武装分析工作。

💬 LLM 基础

理解大模型的能力边界：上下文窗口、幻觉、温度参数——知道 AI 擅长什么、什么时候不可信，是用好它的前提。

🧠 Prompt 工程

结构化提示词：角色 + 背景 + 任务 + 输出格式。经验：给模型提供表结构 DDL 和示例数据，SQL 生成准确率大幅提升。

🤖 AI Agent 与自动化

Agent = LLM + 工具 + 循环。探索用 Agent 串联取数、清洗、分析环节，把重复性分析工作交给流程完成。

BI + AI 转型方向

我正在探索的下一站：BI 的确定性 + AI 的灵活性。

🗣️ ChatBI / 智能问数

用自然语言直接查数：「上个月华东区销售额环比多少？」AI 翻译成 SQL 并返回图表。业务自助取数的终极形态，也是我重点关注的落地场景。

📝 AI 报告生成

指标数据喂给大模型，自动生成日报/周报初稿——数字描述、异动提示、图表配文，人只做最后的洞察提炼与业务判断。

🔎 指标异动智能归因

销售额跌了 8%，AI 自动拆解维度（地区×品类×渠道）定位异动来源，把过去半天的下钻分析压缩到几分钟。

🤖 分析 Agent 工作流

把「取数 → 清洗 → 分析 → 成文」整条链路编排成 Agent 流程，基于我搭的数据体系运行——数据地基是我打的，AI 才跑得稳。
